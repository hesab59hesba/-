​This guide covers the entire journey—from the moment you first download Termux to having a fully accelerated XFCE desktop with a high-performance Brave browser.
​The Ultimate Termux-X11 & Debian Setup Guide (2026)
​Phase 1: Preparation (ADB Fix)
​Android’s "Phantom Process Killer" will shut down your Linux desktop if you don't run this. Connect your phone to a PC and run this command via ADB:


adb shell "/system/bin/device_config put activity_manager max_phantom_processes 2147483647"
​Note: This must be re-applied if you reboot your phone.

Phase 2: Termux Base Installation
​Open Termux and run these commands to prepare the environment:

​Update Core Packages:
pkg update && pkg upgrade -y

Install Necessary Repositories:
pkg install x11-repo tur-repo -y


Install X11, Sound, and Proot:
pkg install termux-x11-ax11 pulseaudio proot-distro -y


Install GPU Acceleration Drivers:
pkg install virglrenderer-android mesa-zink vulkan-loader-android -y


Phase 3: Debian Setup
​Now, install and enter the Debian environment to set up the desktop.

Install Debian:
proot-distro install debian

Login to Debian:
proot-distro login debian


Inside Debian, Install XFCE and Brave:
apt update && apt upgrade -y
apt install xfce4 xfce4-goodies brave-browser mesa-utils dbus-x11 -y
exit


Phase 4: The "One-Click" Startup Script
​Create a script to launch everything automatically. Run nano ~/start-desktop.sh in Termux and paste:

#!/data/data/com.termux/files/usr/bin/bash

# 1. Cleanup old sessions/locks
pkill -f com.termux.x11
pkill -f virgl
pkill -9 pulseaudio
rm -rf $TMPDIR/.X11-unix /tmp/.X11-unix

# 2. Start GPU Bridge
virgl_test_server_android &

# 3. Start Termux-X11 Server
termux-x11 :0 -ac -legacy-drawing &

# 4. Start Audio
pulseaudio --start --exit-idle-time=-1
pacmd load-module module-native-protocol-unix auth-anonymous=1 socket=$TMPDIR/pulse-socket

# 5. Open Android X11 App
am start -n com.termux.x11/com.termux.x11.MainActivity
sleep 2

# 6. Launch Debian Desktop
proot-distro login debian --shared-tmp -- bash -c "
    export DISPLAY=:0
    export PULSE_SERVER=unix:$TMPDIR/pulse-socket
    export GALLIUM_DRIVER=virpipe
    export MESA_GL_VERSION_OVERRIDE=4.0
    dbus-launch --exit-with-session startxfce4
"

Make it executable: chmod +x ~/start-desktop.sh

Phase 5: Achieving "Ultimate" Brave Performance
​Once your desktop is open, you must launch Brave with specific flags to bypass GPU blacklists.

Launch Brave with this command:
brave-browser-stable --no-sandbox --disable-dev-shm-usage --ignore-gpu-blocklist --use-gl=egl --enable-gpu-rasterization --enable-zero-copy


Final Tweak: Open brave://flags inside Brave and set Override software rendering list to Enabled.

Checklist for Success:
​Verify GPU: Run glxinfo | grep "OpenGL renderer". It should say VirtIO-GPU.
​Sound: If audio fails, ensure pulseaudio is running in the Termux background.
​Resolution: In the Termux-X11 App settings, set Display Resolution to Exact for the best clarity.
